# apothemm — сайты для бизнеса

Портфолио: https://apothemm.github.io/

Статический сайт с тремя демонстрационными страницами: архитектурное бюро FORMA, предметный бренд OBJECT и кофейня PAUSE. Все бренды вымышленные; проекты показывают варианты дизайна и не являются заказами клиентов. Иллюстрации созданы с помощью ИИ.

Анимации учитывают prefers-reduced-motion. Форма готовит текст заявки локально и открывает Telegram @apothemm; отправка выполняется пользователем. Сервер, аккаунт и сборщик не требуются.

## Локальный запуск

```sh
python -m http.server 8765
```

Откройте http://localhost:8765. GitHub Pages публикует ветку main из корня репозитория.
